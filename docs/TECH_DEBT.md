# TECH_DEBT.md —— 技术债与未决项

1. **record_key 长度假设 ≤255 字符**：与 MySQL 组合主键容量匹配；越界键属越界数据，
   后续可按需加 SHA-256 映射（预留。
2. **TLS 强制未启用**：`STORAGE_SSL_REQUIRED` 保留配置位，但未接入 mysql2 `ssl`
   选项的强制模式（届时由云服务商提供）。
3. **无读从库**：本轮读写共用一池；如需读写分离仿 session 增加 `MYSQL_READ_*`。
4. **无进程内缓存**：每写一句 SQL，牺牲少量延迟换取权威/一致；若后续成为热点可加
   按 unit 的内存写缓冲 + 周期落盘（需重新评估崩溃语义）。
5. **index.ts 分支覆盖 66%**：schema 迁移失败分支由 fail-closed 语义保证，未逐条覆盖。
